# First Look · 给自己的第一封短笺

2026-11-18。首次进入时的十题自我探索，默认英文，可当场切换简体中文。没有人格代码、评分或类型。每题四选一，支持返回修改、未完成续答、暂存离开和从「我的」查看或重答。完成或跳过后，不再因冷启动或后台返回而强制重测。第十题提交后进入独立加载页；可取消回到答案，网络失败也保留回答。重答成功前保留旧报告。

## 十道问题

1. 当你说“我没事”的时候，最希望对方怎么做？
2. 哪一个瞬间，最容易让你觉得“这个人懂我”？
3. 你很想提出一个请求，最后却没有说出口。最可能是因为什么？
4. 重要的人突然变得冷淡，你最先做的通常是什么？
5. 终于有一个完全属于自己的晚上，你更想怎么过？
6. 如果今天只能被认真听见一句话，你想说哪一句？
7. 做一个可能让别人失望的决定时，什么最难放下？
8. 一次争执之后，什么最能让你重新靠近？
9. 如果暂时不用向任何人证明什么，你最想允许自己怎样？
10. 读完这份报告之后，你最希望带走什么？

题目与选项的唯一来源为 `INVERTER/Resources/FirstLookQuestions.json`，中英文共用稳定 ID。版本为 `first-look-v1`；改变选项含义时需同步版本与服务端题库，不能复用旧 ID 改写历史答案。

## 短笺与图片

完成十题后直接请求生成短笺，不再提供 AI／本地模式选择。未登录时先完成短信登录；登录关闭后继续原请求。生成失败停留在答题页，保留全部选择，可以重试；不再用本机模板冒充生成结果。旧版本已经保存的短笺仍可阅读，并可点击「重新写一封」更新。重答成功前保留原报告。

报告保存语言、完整十题选择、生成来源、时间和提示词版本，来源用于内部追溯，不再在海报中展示处理方式。报告采用白纸、黑字、细灰线与轨道图，输出 1080 像素宽、随内容增长的完整图片。长按可保存或分享，也有显式按钮。保存时仅申请相册添加权限，分享使用系统面板；支持微信分享扩展或保存后发送。图片含短笺、品牌和「自我探索，非心理诊断」，不附完整答题记录、手机号或姓名。

## 统一生成服务

`Backend/soulmark_extension/first_look.py` 的 `SYSTEM_PROMPT` 是固定写作提示。输入为全部十题及所选答案，要求温暖、具体、有节制的第二人称回应，至少两处观察有实际选择为依据。允许表达内心拉扯，不编造童年、创伤、临床判断、隐藏动机或命运预测。中文目标 180–320 字，英文 110–170 词，标题是一句回应。

用户点击生成时直接发送本次回答，无模式开关或二次技术说明弹窗；隐私页集中说明相关回答会发送到服务端和千问平台。请求不附其他档案、图片、录音或旧云端记忆。原 `allowCloud` 字段只为兼容存档而保留，不再控制产品功能。后端不读记忆、不写数据库，失败返回明确错误并保留已有报告。

2026-11-18 已使用新 Key 对短笺中英文、复盘追问及六类分析进行真实模型联调，均返回有效结构。新 Key 对应千问平台 `https://maas.qianwenaiapi.com/compatible-mode/v1`，统一使用 `qwen3.7-plus`。模型密钥保存在仓库外的部署配置中，不进入 App 或 Git。
