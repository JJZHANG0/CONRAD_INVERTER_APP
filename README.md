# INVERTER

**Understand Others. Understand Yourself.**

基于产品提示词实现的 SwiftUI 原生 iOS App 原型。四个主页面均可操作，记录、人物、探索报告、挑战及授权设置保存在本机。视觉采用白、黑、灰的简约排版，RealityKit 三维关系球以冰蓝到暖粉展示用户标注的亲密程度。

## 运行

1. 在 Xcode 中打开 `INVERTER.xcodeproj`。
2. 选择 `INVERTER` scheme 和 iPhone 模拟器，按 **⌘R**。
3. 首次进入可完成十题自我探索，也可暂存离开。完成或跳过后，冷启动及后台返回直接进入首页；可在「我的」主动重答。第十题提交后显示独立加载页，失败保留答案。
4. 真机运行时，在 Signing & Capabilities 中选择自己的开发团队。

工程沿用创建时的 Xcode 27.2 `project.xcproj` 格式；请用支持该工程格式的 Xcode 打开。部署目标为 iOS 17.0。没有第三方依赖，无需安装包管理工具。

## 可以体验的流程

- **初见短笺**：十道中英问题、未完成续答、情感反馈长图、长按保存、系统分享。直接生成情感短笺，失败保留回答并可重试，不提供处理模式选择。见 [功能说明](Documentation/FirstLook.md)。
- **首页 bot 与聊天**：首页右侧为黑白动态表情，支持双眨眼、眨单眼、侧头、点头、多种几何变形和说话动作。点击进入主动引导的对话，可选择情绪梳理、关系边界、自我理解、行动勇气四个模式，Bot 随之切换冰蓝、暖粉、淡紫、琥珀色。每个模式有独立的提问路径与收束目标，文字／语音和报告共享所选模式。信息充分时主动收束，也可手动结束并生成可保存分享的长图。中英文统一使用千问网关。
- **首页**：事件复盘入口、可回溯依据的今日认知、每月挑战、快捷导航。
- **复盘**：事实 → 感受 → 个人解释 → 在意点 → 下一步；支持返回修正、最终逐项确认、人物关联、保存、收藏、编辑和删除。
- **语音对话**：独立全屏通话页，设备端中英语音识别与朗读交替进行。停顿约两秒自动提交，支持手动提交、静音、打断、挂断及后台结束；识别不可用时回到文字。不是全双工流式音频，真机麦克风和路由体验仍需实际验收。
- **输入**：文字、中英设备端语音识别、照片／聊天截图附件。图片压缩后仅保存在本机；此版不做 OCR 或图像分析。设备不支持离线语音识别时明确提示使用文字。
- **对内**：六个认知维度及记录依据、情绪分类时间图、情绪筛选、成长记录。
- **六种探索游戏**：价值排序（拖动及无障碍箭头调整）、情境选择、情绪识别、边界探索、认知偏好、优势发现；各自提供完整步骤、自定义回答、反思、事件关联和报告，支持重新体验。
- **Connect**：28 个示例人物、更密集经纬线的三维关系球，保留旋转／惯性／缩放／复位。连线与头像边缘按用户标注的亲密程度从冰蓝过渡到暖粉，未标注为灰色。顶部明确提供「添加关系」与「导入通讯录」，支持「未分类」筛选。
- **人物档案**：姓名、分类、头像、可省略年份的生日、常见公历日期星座、喜好、厌恶、相处细节与组织信息，支持编辑及本机持久化。星座仅作资料展示，不推断人格。
- **通讯录导入**：系统多选联系人 → 预览 → 选择分类 → 确认。默认未分类、亲密程度未标注；只保存姓名、头像、生日、组织与本机去重标识。重复联系人不覆盖手工修改，同名不同联系人保持独立。头像统一用于列表、档案及球体节点。
- **成长挑战**：四个行动步骤、完成反馈、修改反馈、暂停与换主题。
- **我的**：个人资料、历史搜索、收藏、游戏记录、记忆管理、类别授权、JSON 导出、清除数据、可选本机通知。

## 数据和认知规则

- 示例来自 `DemoData`，不会写入个人档案，不计入个人统计，不进入长期记忆。示例与个人记录不会混合生成洞察。
- 洞察只聚合用户明确写下的相同在意点，至少两条记录才显示；每条都能回看依据。没有自动生成的人格分数、关系评分或临床推断；亲密程度由用户自行标注。
- 长期记忆默认关闭。事件记忆必须同时满足**类别授权 + 本次保存确认**。游戏记忆在独立授权后以个人解释保存。
- 修正事件时删除由旧内容衍生的记忆；洞察随源数据重新计算。修正单条记忆会替换旧内容并标记「已修正」。
- 删除事件会清除关联记忆并解除游戏报告引用。删除人物解除事件关联，保留事件正文。删除游戏报告会同步删除其记忆。
- JSON 使用原子写入和 iOS 完整文件保护。读档失败时保留原文件并停止覆盖；新建记录和游戏报告写入失败不会显示保存成功。
- 本机记录不自动云同步。可使用原 SoulMark 短信账户请求 AI 分析；仅发送用户请求生成时的相关文字。旧账户已有的云端数据由原服务管理。

## 服务与外观升级

默认英文，可在 Profile → Appearance & language 切换完整简体中文，并选择 System / Light / Dark。页面采用白、黑、灰的动态颜色；关系球的冰蓝—暖粉配色同步适配外观。用户输入和旧存档保持原文，枚举持久化值不因翻译改变。

短信登录和 JWT 身份延续 SoulMark。十题短笺、复盘逐轮追问、记录、探索报告、人物、画像、挑战和洞察统一调用千问服务。界面去掉 AI／本地选择和二次发送说明；隐私页集中说明数据用途。输入与已有报告在网络失败时保留，用户可以重试。

新网关已安装到香港 ECS `47.76.244.254`，App 服务地址为 `https://47-76-244-254.sslip.io`。公网 HTTPS、未登录拦截及 8 项真实模型请求全部通过，证书自动续期已启用并通过演练。模型 Key 只保存在服务端及仓库外私有开发配置中，不写入 App。真实短信投递仍需单独验收。

## 工程结构

```text
INVERTER/
  Models/       核心实体、示例数据、六种游戏内容
  Services/     Observable AppStore、持久化、AI 接口、离线语音
  Design/       色彩、排版、按钮、通用组件、矢量轨道图
  Features/     首页／对内／关系／我的／复盘／游戏／档案／挑战
  Assets.xcassets/
  Resources/English.json  完整应用文案与插值翻译
  InfoPlist.xcstrings     系统权限文案
INVERTERTests/   数据和授权规则测试
INVERTERUITests/ 真实模拟器流程测试
Scripts/        可重新生成的原生 App 图标
Documentation/  接口约定、模拟器截图
```

使用 Observation 状态管理与独立服务层，路由由主 Tab 枚举、各页 NavigationStack 和类型化 sheet 管理。采用 Codable 文件存储，让导出、错误恢复和与 Django/FastAPI 对接的字段保持清晰；未沿用模板中的无业务含义 SwiftData Item。

## Bot 素材来源

使用 [ThePeeps191/grok-bot-characters](https://github.com/ThePeeps191/grok-bot-characters) 的 MIT 授权几何数据，固定版本 `49bde09a6a2d13b08fa2ddd3a59a6fca2dc69e8e`。本应用用 SwiftUI Canvas 原生绘制黑白表情，不加载网页或外部素材；减少动态效果开启时停用连续动画，后台和离屏暂停。版权及许可随 App 打包在 `GrokBot-LICENSE.txt`。`node Scripts/GenerateBotShapes.cjs` 可从保留的上游代码重建几何数据。

完整聊天记录只在当前进程保留；生成的对话回顾及依据保存在本机，不加入长期记忆。聊天页右上角可查看历史回顾，隐私页可导出或清除。分享图片不包含原话依据，但仍可能涉及个人经历，分享前需检查。每次请求仅发送有界对话上下文。
